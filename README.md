# Dr. Osvaldo L. Santos-Pereira - Personal Academic Site


Site pessoal e acadêmico de Dr. Osvaldo L. Santos-Pereira — HTML/CSS estático, sem build, sem frameworks.

## Publicar no GitHub Pages

1. Crie (ou use) o repositório `ozsp12/ozsp12.github.io` no GitHub.
2. Copie todo o conteúdo desta pasta para a raiz do repositório (mantendo a estrutura de pastas).
3. Faça commit e push para a branch `main`.
4. Em Settings → Pages, defina Source = `main` / `/ (root)`.
5. O site ficará disponível em https://ozsp12.github.io/

## Estrutura
- `index.html` — Home
- `about/`, `teaching/`, `research/`, `publications/`, `repos/`, `contact/` — demais páginas
- `assets/css/style.css` — estilos
- `assets/img/` — imagens
- `.nojekyll` — desativa o processamento Jekyll do GitHub Pages

## Idioma
Alternância PT/EN client-side via CSS (checkbox/radio), sem JavaScript. Conteúdo em ambos os idiomas está presente no HTML; PT é exibido por padrão.
