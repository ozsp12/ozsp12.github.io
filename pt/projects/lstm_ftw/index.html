Como interpretar este dashboard

Proveniência e limitações

Dados. A página lê apenas o lote sintético de entrada mais recente. Linhas de treinamento não entram nos resultados exibidos.

Versionamento. latest.json resolve a execução mais recente. Cada execução é mantida e expõe um analysis.json canônico; a tabela do artigo é gerada da mesma fonte.

Aprendizado contínuo. Uma fração controlada das avaliações de entrada marcada como goldtest é promovida após a avaliação. O histórico de treinamento existente é preservado entre workflows.

Escopo. As métricas caracterizam uma distribuição controlada do gerador sintético. Não há avaliação em dataset externo real e, portanto, o dashboard não reivindica generalização externa.
